# CDG Browser para Android

CDG Browser es una aplicación Android nativa basada en GeckoView.

## Compilar la APK Android

Requiere JDK 17 o posterior y Android SDK con plataforma 37.2 y Build Tools 37.0.0. GeckoView 160 requiere compilar con API 37.2; la aplicación sigue orientada a API 36.

```sh
cd android
./gradlew :app:assembleMobileRelease :app:assembleTvRelease
```

Se genera un APK universal por variante, con bibliotecas para `arm64-v8a`, `armeabi-v7a` y `x86_64`, en `android/app/build/outputs/apk/mobile/release/app-mobile-release-unsigned.apk` y `android/app/build/outputs/apk/tv/release/app-tv-release-unsigned.apk`. Los APK Release no están firmados porque el proyecto no configura una clave de publicación; hay que firmarlos antes de instalarlos o distribuirlos. La variante `mobile` conserva el identificador `com.cdg.browser`; `tv` usa `com.cdg.browser.tv`, incluye entrada Android TV/Leanback y una interfaz con controles grandes y foco para navegación con mando. Se pueden instalar ambas variantes a la vez. Para compilar solo una, usa `:app:assembleMobileRelease` o `:app:assembleTvRelease`.

Para generar las variantes Debug universales, usa `:app:assembleMobileDebug` y `:app:assembleTvDebug`. Para instalarlas en un dispositivo conectado:

```sh
adb install -r android/app/build/outputs/apk/mobile/debug/app-mobile-debug.apk
```

Para instalar la variante Debug de TV en un Android TV, usa `android/app/build/outputs/apk/tv/debug/app-tv-debug.apk`.

La aplicación Android combina la protección estricta de GeckoView con una WebExtension local que filtra solicitudes de terceros usando una lista de hosts incluida en la app. En «Protección» se puede pausar ese filtro, crear una excepción para el sitio actual y actualizar la lista manualmente. La actualización usa [StevenBlack/hosts](https://github.com/StevenBlack/hosts) (licencia MIT), solo tras confirmación; GitHub ve la IP de red, pero no se envían el historial ni la dirección visitada. No hay actualización automática. Las reglas son por host: no eliminan anuncios propios del sitio ni aplican filtros cosméticos, así que no garantizan quitar toda publicidad.

La app desactiva la telemetría móvil de GeckoView y no integra SDK propio de analítica. La navegación normal sigue comunicándose con los sitios que se visitan. El bloqueo estricto integrado de GeckoView continúa activo incluso si se pausan las reglas locales.

La interfaz móvil permite abrir y cambiar entre pestañas y favoritos en un panel lateral izquierdo, y acceder a descargas, ajustes y protección desde el panel derecho. La variante TV comparte las funciones del navegador y adapta los controles a una pantalla grande y al mando D-pad; la barra de dirección permanece visible durante el desplazamiento. Ambas ofrecen cinco temas visuales, motor de búsqueda y página de inicio configurables; las preferencias se guardan localmente. En móvil, la barra agrupa URL, «Ir» y «Actualizar», y se oculta al desplazarse hacia abajo y reaparece al subir o tocar el control superior. «Ajustes» concentra protección, detector multimedia, calidad mínima preferida, fragmentos HLS/DASH, remultiplexado MP4, subtítulos, carpeta de descargas y actualización de yt-dlp. El módulo `:downloads` guarda archivos multimedia que la página ofrece directamente y evita sobrescribir nombres existentes. Cuando se detecta contenido HLS, DASH o video, aparece un botón flotante «Medios» sobre la página; sus tarjetas muestran la miniatura, título, duración y resolución detectados. El botón de descarga analiza los formatos solo al solicitarlo y abre un selector de calidades, priorizando la calidad mínima configurada sin ocultar las opciones menores ni audio. La pantalla «Descargas» combina tareas en curso e historial terminado, permite elegir una carpeta mediante el selector de Android y muestra los archivos disponibles en esa carpeta. La detección no incluye navegación privada y no puede resolver por sí sola URL `blob:` ni garantizar que GeckoView exponga todas las solicitudes.

En móvil, la galería multimedia permite explorar videos descargados y reproducirlos con el reproductor interno Media3, que admite formatos según los decodificadores disponibles en cada dispositivo; no garantiza todos los códecs. Si falla la reproducción, se puede abrir el archivo con otra aplicación. El detector de imágenes encuentra fuentes visibles y variantes de mayor resolución que la página expone, y permite seleccionar hasta 100 imágenes por lote; las descargas se limitan a imágenes HTTP(S) compatibles de hasta 40 MiB cada una. También se pueden poner en cola varios videos detectados, con hasta tres descargas simultáneas mediante yt-dlp. El historial local de enlaces completados evita volver a descargar la misma URL con el mismo formato y se puede consultar o borrar desde «Descargas»; borrar el historial no elimina archivos. Las descargas de imágenes no reutilizan cookies del navegador. La actualización de yt-dlp y de las listas de protección es independiente y manual; el reproductor, el detector y la lógica de la app se distribuyen mediante una APK firmada, no como código descargable.

El botón flotante «Medios» se puede apagar globalmente o esconder en sitios concretos desde Ajustes; esto solo oculta el botón, no detiene la detección. Los medios encontrados se acumulan en la biblioteca del panel lateral para poder seguir navegando entre páginas. Cada tarjeta ofrece «Guardar para después» y «Descargar»: el último analiza las calidades una sola vez y permite elegir formato; la lista guardada permanece localmente al cerrar la app y se puede revisar, quitar o seleccionar desde el panel lateral. Los elementos completados salen de la lista; los fallidos permanecen para reintentar. Desde la biblioteca también se pueden analizar varios videos con yt-dlp y revisar la selección antes de descargar. Las descargas en lote usan la mejor calidad disponible y se limitan a tres simultáneas; los enlaces no compatibles se reportan y no detienen el resto de la cola.

Los enlaces se pueden copiar o analizar con yt-dlp para consultar metadatos y elegir entre los formatos que el sitio expone, extraer MP3 o incrustar subtítulos disponibles. La cadena intenta primero URLs directas y después yt-dlp; no hay extractores nativos específicos de sitios en este proyecto. Los videos se remultiplexan a MP4 sin recodificarlos; los archivos usan el título del medio y, si es genérico, el de la página. Las listas no se descargan como playlist. Para HLS/DASH yt-dlp puede descargar hasta 32 fragmentos simultáneamente; los archivos de video directos dependen del servidor y no se dividen en fragmentos. Los formatos separados de audio y video se solicitan como una combinación y yt-dlp usa el FFmpeg incluido para unirlos cuando es necesario. El gestor muestra progreso, permite cancelar yt-dlp y abrir o compartir archivos. El historial de descargas se guarda localmente; si se cierra la app durante una tarea, al volver se marca como interrumpida y se puede reintentar (no se reanuda desde el byte exacto). yt-dlp no recibe las cookies del navegador y no evita DRM ni controles de acceso; el análisis puede fallar en sitios que requieren autenticación o cuando cambian sus extractores, y las URL de medios pueden caducar.

La actualización estable de yt-dlp es manual. Verifica el digest SHA-256 publicado por la API oficial de GitHub, permite solo redirecciones HTTPS a hosts autorizados, descarga a almacenamiento privado, conserva una copia anterior y valida la versión antes de finalizar el reemplazo. Si el digest no está disponible o falla alguna comprobación, la actualización se rechaza. Los archivos se guardan en `Descargas/CDG Browser` (Android 10 o posterior); en versiones anteriores, quedan en el almacenamiento específico de la aplicación. Descarga solo contenido que tengas derecho a guardar. El motor yt-dlp incluye bibliotecas nativas ARM y las APK se generan para `arm64-v8a` y `armeabi-v7a`.

El panel Protección muestra el estado, los dominios de la lista, los bloqueos de la sesión, excepciones por sitio y actualización manual. El filtro local de anuncios sigue siendo una lista de hosts (sin interpretación general de EasyList ni reglas cosméticas); el filtro y la detección multimedia son independientes. Se pueden bloquear ventanas emergentes no solicitadas y activar el bloqueo estricto de redirecciones posteriores a un clic. Este último puede interrumpir inicios de sesión y cambios HTTP a HTTPS; desactívalo si una página deja de funcionar. Las redirecciones repetidas también se limitan, pero esto no es un servicio de reputación ni protección anti-phishing. Comprueba el dominio antes de autenticarte.
